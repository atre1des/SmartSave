# Built-in profile avatars

Tap the portrait in My Account or Profile to choose from ten OpenMoji animals. Save updates the portrait across the app. Reset to default followed by Save removes the saved choice. Cancel discards the draft.

Only the avatar ID is stored in local preferences under the Firebase account UID. Signing out clears the visible portrait and keeps the preference for the next sign-in. Account deletion also removes the stored preference.
